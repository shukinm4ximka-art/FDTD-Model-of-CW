# FDTD

Численная модель радиоканала «источник → антенна → канал → декодер»:
3D FDTD-решатель уравнений Максвелла (PascalABC) передаёт сообщение
азбукой Морзе через виртуальный полуволновой диполь, Python-декодировщик
принимает его. Весь «эфир» помещается в оперативной памяти ноутбука —
ни регистрируемой радиостанции, ни эфирного позывного не требуется.
