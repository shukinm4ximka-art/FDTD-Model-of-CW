# FDTD-радиопередатчик на Паскале: морзянка в оперативной памяти

Численная модель радиоканала «источник → антенна → канал → декодер»:
3D FDTD-решатель уравнений Максвелла (PascalABC) передаёт сообщение
азбукой Морзе через виртуальный полуволновой диполь, Python-декодировщик
принимает его. Весь «эфир» помещается в оперативной памяти ноутбука —
ни регистрируемой радиостанции, ни эфирного позывного не требуется.

## Состав

- `антенна с импедансом и портом.pas` — решатель FDTD 3D с CW-манипуляцией
  (PascalABC.NET). Диполь вдоль x: плечи по 5 ячеек + зазор 1 ячейка,
  сетка 30×30×30, несущая ~15,2 ГГц (λ ≈ 19,7 мм), источник напряжения
  V0 = 10 В, губка-поглотитель, морзянка «MAX2».
- `gap.txt` — лог диагностики порта: V(t) и I(t) в зазоре (пример прогона).
- Статья на Хабре- https://habr.com/ru/articles/1111382/

## Ключевые результаты

| Величина | Значение |
|---|---|
| Несущая | ~15,2 ГГц (λ ≈ 19,7 мм) |
| Шаг по времени | 1,83 пс (Курант ×0,95) |
| Входной импеданс (ДПФ на несущей) | Z = 107,7 − j1181 Ом |
| Мнимость после де-эмбеддинга ёмкости зазора | ≈ +2 Ом (резонанс) |
| Средняя мощность на несущей | 1,55 мВт (пик 46 мВт) |
| Энергия сообщения «MAX2» | ~0,17 нДж за 128 нс модельного времени |
| Сжатие времени | ~3·10⁷ раз |

Ёмкость пустой ячейки зазора C = ε₀A/d = 8,9 фФ даёт X = −1183 Ом —
измеренная мнимость −1181 Ом совпадает до третьей значащей цифры.

## Запуск

1. PascalABC.NET: открыть `антенна с импедансом и портом.pas`, выполнить (F9).
   Код рисует срез Ez и график энергии W(t), сохраняет кадры и
   пишет `gap.txt` / `probe_cw_антенна.txt`.
2. Декодировщик и анализ `gap.txt` — на Python (скрипты добавляются).

## Ограничения модели

Идеальный источник напряжения, идеальный ключ, порт без калибровки.
Губка — не PML в строгом смысле; область 0,75λ, сетка 20 ячеек на λ,
провод толщиной в ячейку. Препятствия и помехи не учитываются.
Планы: резистивный порт, S11, CPML, дальнее поле.
